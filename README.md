# アダマス工房

ポケモンチャンピオンズ（レギュM-C・Lv50固定）向け、**はがね統一チーム**の構成支援＆ダメージ計算ツール。

## 特徴

- **はがね図鑑**: はがねタイプ全79系統・94フォルムの閲覧・検索・タイプ絞込み・種族値ソート・自軍追加
- **チーム管理**: ★手持ち（最大6体）＋ベンチの管理、AP配分（合計66上限）・性格・持ち物・フォルム・技構成の編集
- **ダメージ計算**: 与ダメ／被ダメ、16乱数・確定数判定、タイプ相性、HPバー可視化、ステルスロック着地計算。
  戦闘条件は 能力ランク／天候5種／フィールド4種／てだすけ／複数体攻撃／壁／急所／やけど／
  持ち物／特性（攻撃18・防御16。無効化と かたやぶり・まもる貫通を含む）に対応
- **素早さ比較**: ★手持ち vs 環境レポケモンの速度ライン（最速／準速／無振り）、スカーフ・Sランク補正
- **確実なローカル永続化**: `localStorage` へ自動保存＋JSONエクスポート/インポート（端末間移行・バックアップ用）

## データ出典

- **技データ**（タイプ・威力・分類・命中率・PP・接触/パンチ/音/かみつき/波動/弾のフラグ）:
  [PokeAPI](https://github.com/PokeAPI/pokeapi) の CSV。`tools/audit-moves` で検証、
  `tools/gen-move-meta` で再生成できる。
- **チャンピオンズの習得技**: AppMedia の各ポケモン個別ページ（`tools/scrape-learnsets`、GitHub Actions から取得）。
- **特性・技の仕様**（効果の細部）: [ポケモンWiki](https://wiki.pokemonwiki.com/) を参照。
  チャンピオンズ独自の特性（`かんつうドリル` = `ふかしのこぶし` と同効果、`マイティチェンジ` など）は
  実機・Wikiの記載を確認して実装している。
- 本編と値が違うチャンピオンズ独自の技は `tools/audit-moves` の `CHAMP_OVERRIDES` に登録する
  （現状: トラバサミ＝はがね）。

> AppMedia・ポケモンWiki はこのリポジトリの開発環境（Claude Code）からは直接取得できないため、
> 取得が必要な場合は GitHub Actions のランナーから実行する。

## 技術スタック

- React 18 + TypeScript + Vite
- 状態管理は React Context（`src/store.tsx`）
- 永続化は `localStorage`（`src/storage.ts`）

## 開発

```bash
npm install
npm run dev      # 開発サーバ
npm run build    # 本番ビルド（tsc 型チェック + vite build → dist/）
npm run preview  # ビルド成果物のプレビュー
```

`VITE_BASE` 環境変数でサブパス配信に対応（例: GitHub Pages 用に `VITE_BASE=/adamas/ npm run build`）。

## データ構造と拡張

いずれも「データを追記するだけで機能拡張できる」設計を維持しています。

- **はがね図鑑**: `src/data/dex.ts` の `DEX`（`megaOnly: true` はメガで初めて鋼化する系統）。
  ポケモンチャンピオンズ内定準拠の **22系統**（ユーザー提供の内定一覧スプレッドシート由来）。
  SV全体のはがねリストから未内定58系統を除外して再構成済み。
- **全内定ポケモン（仮想敵プール）**: `src/data/confirmed.ts` の `CONFIRMED`（全317フォルム）。
  No.・名前・種族値・特性は内定一覧の一次ソースに一致。タイプはシリーズ共通の確定値。
  `typeVerified: false` はチャンピオンズ新規メガ等で公式タイプ未公表のため素の型を仮採用（UIで要確認表示）。
  ダメージ計算タブの仮想敵は、このリストから名前絞込みで選択でき、種族値・特性・タイプを自動補完する。
- **仮想敵（素早さ比較の速度ライン）**: `src/data/dex.ts` の `THREATS`（代表的な環境ポケモンの curated リスト）
- **技ライブラリ**: `src/data/moves.ts` の `MOVE_LIB`
- **種族別習得技**: `src/data/moves.ts` の `LEARNSETS`
  - `status: "full"` = 全習得技を検証済み ／ `status: "partial"` = 一部のみ検証済み
  - **現状の収録範囲**: 完全収録=ボスゴドラ、部分収録=ブリジュラス/アーマーガア/メタグロス/ギルガルド/チリーン/デカヌチャン
  - 未収録の72系統は「全技ライブラリ＋習得可否未検証の警告」で表示される。1系統ずつ攻略サイトで裏取りして `LEARNSETS` に追記していく想定

## 計算エンジンの仕様（`src/calc.ts` / `src/data/game.ts`）

- 実数値: Lv50・個体値31固定の検証済み計算式（`realStats`）
- ダメージ: 先頭係数22、五捨五超入（`pokeRound`）、STAB（てきおうりょくは2.0倍）、16乱数（85〜100%）
- 確定数: 16分岐一様乱数を動的計画法で追跡し「確定n発／乱数n発（%）」を判定

### 仕様上の非対応（意図的スコープ外・UIにも明示）

- 威力可変技（ヘビーボンバー・けたぐり・きしかいせい・がむしゃら・ジャイロボール等）→ 手動で威力指定
- 連続技（ロックブラスト・つららばり等）
- がんじょう・きあいのタスキ・ばけのかわ等「1発耐え」効果
- 特性・持ち物補正は主要なもの（かたいツメ／ちからずく／ちからもち／てきおうりょく／こだわり系／いのちのたま／たつじんのおび／とつげきチョッキ／フィルター系／マルチスケイル）のみ

## 既知のデータ注意点

- メガメタグロスの防御実数値は AppMedia 表記「145」に対し、種族値合計+100則との整合から本ツールは種族値150を採用（実機での最終確認推奨）
- ザシアン・ザマゼンタは「けんのおう／たてのおう」のみ収録
