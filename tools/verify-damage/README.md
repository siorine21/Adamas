# ダメージ計算の検証

`src/calc.ts` の `computeDamage` が本編どおりに計算できているかを、
本家の [@smogon/calc](https://github.com/smogon/damage-calc) と突き合わせて確かめます。

```bash
npm i --no-save @smogon/calc esbuild
npx esbuild src/calc.ts --bundle --format=esm --outfile=tools/verify-damage/ours.mjs
node tools/verify-damage/verify-damage.mjs
```

16乱数がすべて一致すれば OK です（`一致 55 / 不一致 0`）。

## なぜ必要か

ダメージ計算は「どの順番で補正を掛けるか」で答えが変わります。本家は補正を
4種類の連鎖に分けていて、それぞれ最後に1回だけ丸めます。

| 連鎖 | 中身の例 |
| --- | --- |
| 威力補正 | かたいツメ・ちからずく・テクニシャン・てつのこぶし・てだすけ・タイプ強化アイテム・フィールド |
| 攻撃補正 | ちからもち・こんじょう・こだわり系・ピンチ特性・あついしぼう |
| 防御補正 | とつげきチョッキ・しんかのきせき・ファーコート・ふしぎなうろこ |
| 最終補正 | いのちのたま・たつじんのおび・壁・マルチスケイル・フィルター・スナイパー |

複数体攻撃（0.75倍）と天候は**乱数の前**に基本ダメージへ掛かります。
これを取り違えると数点ずれるので、計算式に手を入れたら必ずこのテストを通してください。

## 対象外

- 技の威力・命中・PP そのもの（チャンピオンズ独自の値は `tools/audit-moves` で検証）
- チャンピオンズにしか無い特性（はどうのぼうご など）は本家に無いので比較できない
